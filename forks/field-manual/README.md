# Field Manual

A print-style Eleventy fork of the *Working With LLMs* guide: warm paper, a serif at a strict measure, chapters instead of doc pages, and true margin sidenotes. Self-contained — no dependency on the main MkDocs site.

## Run it

```
npm install
npm run dev
```

Then open `http://localhost:8080`.

`npm run build` produces a static site in `_site/`.
